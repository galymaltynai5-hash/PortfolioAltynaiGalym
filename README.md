# Портфолио Ғалым Алтынай

Статический сайт на HTML и CSS. Не требует сборки или установки пакетов.

## Локальный просмотр

Откройте index.html в браузере.

## Публикация через GitHub Pages

1. Создайте отдельный публичный репозиторий на GitHub, например altynai-portfolio.
2. Загрузите в него index.html и favicon.svg.
3. Откройте Settings → Pages.
4. Выберите ветку main и папку / (root), затем нажмите Save.
5. После публикации GitHub покажет адрес сайта.

Перед публикацией проверьте актуальность сведений, укажите ссылку на профиль GitHub и добавьте ссылки на репозитории проектов, когда они будут доступны. Страница не содержит телефон, дату рождения или сведения о местах стажировок.
