# Ғалым Алтынай Бекзатқызы

## Портфолио в сфере информационной безопасности

Разрабатываю инструменты для мониторинга, анализа событий и автоматизации реагирования на инциденты.

### Избранные проекты

- **Vortex Security** — система мониторинга VR-устройств с desktop-панелью, сервером и Android-агентом.
- **AutoSIEM** — прототип для просмотра и фильтрации событий безопасности.
- **Мониторинг логов** — учебный прототип обнаружения серии неудачных SSH-входов.

В проектах использую C#, .NET, Python, SQLite и SQL Server.
